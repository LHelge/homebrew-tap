# homebrew-tap

A [Homebrew](https://brew.sh/) tap for [Granit](https://granit.lhelge.se/), a minimal desktop note-taking app for macOS (Apple Silicon).

## Install

```sh
brew tap lhelge/tap
brew install --cask granit
```

Or in a single command:

```sh
brew install --cask lhelge/tap/granit
```

## Updates

Granit updates itself through its built-in Tauri updater, so you do not need to run `brew upgrade` to get new versions. The cask is published mainly for first-time installation.
